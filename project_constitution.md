# DAYA Project Constitution

## Mission
To build an emotionally intelligent behavioral support ecosystem for autistic children and their parents. DAYA is a behavioral intelligence platform, a parent support companion, a child pattern memory system, a daily planning assistant, and a continuity-of-care ecosystem.

## Core Identity
- **Not:** a generic chatbot, a medical app, a cure system, a therapy replacement, or an enterprise dashboard.
- **Is:** an adaptive behavioral intelligence system that builds deep, child-specific understanding while treating the parent's wellbeing as the primary therapeutic environment.

## Product Pillars
1. **Behavioral Intelligence & Daily Support:** Check-ins, pattern detection, longitudinal memory, daily/meal planning.
2. **Therapy / School / Shadow Teacher Recommendations:** Premium booking flows and directories for care continuity.
3. **Parenting & Community Support:** Workshops, groups, and emotional support networks for caregivers.
4. **Doctor / Therapist Reports:** Exportable, 30-day longitudinal summaries for medical professionals.

## Design System & Aesthetics
- **Vibe:** Emotionally safe, premium, warm, breathable, deeply human, elegant.
- **Style:** Rounded-3xl cards, soft shadows, large padding, gentle gradients, smooth motion, modern typography.
- **Palette:** Soft Warm Cream (#FAF7F2), Off White (#FDFCF9), Muted Sage Green (#A8C3A0), Dusty Lavender (#C8B6D8), Soft Sky Blue (#B8D7EA), Warm Peach (#F4C7B8), Calm Terracotta (#D99873), Soft Gold (#E7C98B).
- **Anti-Style:** No harsh contrast, no neon "AI" feel, no clinical/hospital visuals, no boring white walls.

## Technical Architecture
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, shadcn/ui.
- **Backend:** Next.js API Routes, Supabase (PostgreSQL).
- **Intelligence:** Centralized `src/lib/daya` core, longitudinal state, multi-language support.
- **Deployment:** Vercel-ready.

## Monetization (Business Model)
- **Freemium:** Basic tracking, chatbot access, basic directory listings.
- **Premium:** Advanced behavioral analytics, predictive recommendations, unlimited therapist-ready reports.
- **Transactional:** Booking commissions for therapy, workshops, and shadow teachers.
